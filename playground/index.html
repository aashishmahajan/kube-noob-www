kube-noob, running in your browser

These are kube-noob's real tools (the same code as the CLI and the MCP server), running in this tab on Pyodide, a build of Python for WebAssembly. No model, no backend, no account: what you paste never leaves your device. The first run downloads the runtime (about 18 MB) from this site, once.
