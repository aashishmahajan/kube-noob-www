deployed kind, audits Containerfiles, and exits 1 at --fail-on. Writes SARIF 2.1.0, a Markdown summary and
GitLab code quality JSON. Offline. Example: helm template app chart/ > rendered.yaml && kube-noob gate -f
rendered.yaml --chart-path chart --platform openshift --version 4.20 --sarif out.sarif

  --values VALUES       values file for --chart; repeat
  --namespace NAMESPACE
                        namespace to render charts into
  --containerfile PATH[=IMAGE][,context=DIR][,target=STAGE]
                        a Containerfile to audit and, with --sarif-report, the build that ships code
                        (context defaults to its directory: context=. for docker build -f
                        deploy/Containerfile .); repeat
  --platform {kubernetes,openshift,rosa-classic,rosa-hcp}
  --version PVERSION    OpenShift (4.20) or Kubernetes (1.33) version
  --exceptions EXCEPTIONS
                        exception list (kube-noob.io/v1 ExceptionList)
  --fail-on {info,low,medium,high,critical,never}
  --skip-unreadable     gate the files that could be read and list the rest under 'unreadable' in the
                        report; without it a file that is not UTF-8 or not YAML exits 5, which a pipeline
                        can tell apart from 1 (findings at or above --fail-on)
  --chart-path CHART_PATH
                        the chart in the repository: findings point at its templates
  --sarif SARIF         write SARIF 2.1.0 here (GitHub code scanning)
  --summary SUMMARY     write the Markdown summary here ($GITHUB_STEP_SUMMARY)
  --codequality CODEQUALITY
                        write GitLab code quality JSON here
  --scanner-report SCANNER_REPORT

  --source-root SOURCE_ROOT

                         [--format {text,json,yaml}]
                         {scan,snapshot,diff,report} ...

Ranks paths from a Route, Ingress, LoadBalancer or NodePort Service to the pods it reaches and what they can
do: node access (privileged, hostPath, host namespaces) or Kubernetes API rights through the ServiceAccount
token (read Secrets, exec, create workloads, escalate). Score = exposure x blast radius. Secrets are never
read. Example: kube-noob posture scan -f k8s/

positional arguments:
  {scan,snapshot,diff,report}
    scan                Rank the attack paths in manifests (-f) or the live cluster (--live)
    snapshot            Record the objects' hashes and today's findings (no values) to a file
    diff                What changed between two snapshots: objects, new and fixed findings, owners
    report              Snapshot now, compare with the newest snapshot kept, write the report (the daily
                        job)

options:
  -h, --help            show this help message and exit
  --config CONFIG       Path to kube-noob.yaml (default: lookup chain, see docs)
  --web-enabled         Override webEnabled: true for this invocation
  --cluster-enabled     Override cluster.enabled: true (read-only)
  --format {text,json,yaml}

                        removed)
