Helm values

Chart kube-noob 0.7.1 (app 0.7.1). Defaults are secure: no web access, no cluster access, authenticated HTTP, NetworkPolicies on, runs under restricted-v2. The chart validates values against values.schema.json. Install and operations: Helm chart, OpenShift.

jira
jira.syncLocal copy of Red Hat's public Jira (redhat.atlassian.net) so answers can say "reported as OCPBUGS-12345: fixed in 4.21.3" or "closed as Not a Bug". The sync reads tickets through Jira's REST API, at most one request per second and maxRequests per run, every intervalHours, and keeps them on the PVC; ticket text never leaves the pod. Needs persistence.enabled, replicaCount 1 and egress to redhat.atlassian.net:443 (opened below when enabled); refused under config.offline. Without egress, build the copy elsewhere and import it: kube-noob corpus import <tgz>. Disk: the copy keeps every comment of every ticket, so give it room (raise persistence.size to 10Gi for the default projects) and check the volume's use after the first full sync.

jira.sync.maxRequests600per run, one second or more apart: about 60,000 tickets a run at most

db.enabledfalseThe public kube-noob-db image: the documentation corpus with its licenses, release history and the release-note known issues, rebuilt daily, signed, and checked to hold no Jira data and nothing that may not be redistributed. An init container copies the archive; kube-noob serve imports it on start when it is newer than the one the data folder already has, so rolling out a newer digest refreshes every pod. admission
admission.enabledfalseTier A: kube-noob-admission, a validating webhook. Every kube-noob finding of a created or updated object becomes an admission warning (kubectl prints them); a request is denied only for a rule listed in enforce, and on UPDATE only for a finding the old object did not have. failurePolicy Ignore and timeoutSeconds 3: a dead or slow webhook never blocks the cluster. The system namespaces, openshift-*, the release namespace, excludedNamespaces and any namespace labelled kube-noob.io/admission=disabled are skipped, as are Pods, ReplicaSets and Jobs owned by a controller (their owner was checked). It never mutates and fetches nothing; lookups add read-only lists.
admission.replicaCount2
admission.enforce[]rule ids to deny, e.g. [KN-S001]; empty = warnings only
admission.excludedNamespaces[]
admission.exceptions""an ExceptionList (kube-noob.io/v1, as for kube-noob audit --exceptions) as YAML text
admission.lookupsfalseRules about other objects of the namespace (PodDisruptionBudgets, NetworkPolicies, PVCs, HPAs, StorageClasses) warn only with lookups: a ClusterRole that lists those (never Secrets), cached and refreshed with jitter. They are never enforced. Needs networkPolicy.egress.apiServerCIDRs when egress policies are on.
admission.maxWarnings101-50 per request; each is at most 256 characters
admission.platformVersion""e.g. "4.20" or "1.33": version-specific rules (deprecated APIs)
admission.timeoutSeconds31-30

The webhook restarts when the certificate rotates.
