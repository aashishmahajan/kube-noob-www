Audit rules / KN-S024

KN-S024 ingress-nginx controller image below the fixed releases

high · audit / supply-chain

What it finds

The controller image tag is a release; the Kubernetes CVE feed names the releases that fix each ingress-nginx CVE. CVE-2025-1974 (CVSS 9.8, fixed in v1.11.5 and v1.12.1) gives anyone on the pod network code execution in the controller through its validating admission webhook; the later fixes close configuration injection through annotations and paths (CVE-2025-15566 in v1.12.5/v1.13.1; CVE-2026-1580, CVE-2026-24512, CVE-2026-24513 and CVE-2026-24514 in v1.13.7/v1.14.3; CVE-2026-3288 in v1.13.8/v1.14.4/v1.15.0; CVE-2026-4342 in v1.13.9/v1.14.5/v1.15.1).

How to fix it

Run a release that fixes every advisory below (v1.13.9, v1.14.5, v1.15.1 or later), disable the validating webhook (--validating-webhook) until the controller is at least v1.11.5 or v1.12.1, and plan the move to a Gateway API implementation: the project is retired and fixes nothing found after its last release.
