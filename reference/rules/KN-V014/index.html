Audit rules / KN-V014

KN-V014 Duplicate object in bundle

high · validate / schema

What it finds

Two objects with the same kind, namespace and name collide.

How to fix it

Remove or rename the duplicate; the later object silently overwrites the earlier one on apply.

NIST SP 800-53 controls

  • CM-3(2) Configuration Change Control | Testing, Validation, and Documentation of Changes
  • CM-6 Configuration Settings

Check your YAML

Paste it in the playground (it runs in your browser), or run kube-noob audit -f deployment.yaml; kube-noob explain KN-V014 prints this rule. Rule ids never change meaning. All 77 rules.
